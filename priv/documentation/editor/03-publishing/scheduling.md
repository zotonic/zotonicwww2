# Scheduling a page

1. Finish and save the page.
2. Open **Settings & more → Publication period**.
3. Set **Visible from** to the intended start date and time.
4. Set **Visible till** only if the page should stop being available at a particular time.
5. Check the time zone and ensure the end follows the start.
6. Check **Published** and click **Save**.

Before the start, the page should be unavailable to ordinary visitors. After the start, check its public URL and the lists or menus where it should appear.

You are scheduling the page's availability, not a separate version of its text. This does not schedule individual edits to an existing published page. Scheduling an email mailing is a separate task.

To cancel a scheduled publication, clear **Published** and save. To publish now, also change a future **Visible from** date to the intended current or past time. Check **Visible till** as well: an expired end still prevents publication. Recheck the public URL after either change.
