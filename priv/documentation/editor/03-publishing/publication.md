# Publishing and unpublishing

## Publish

1. Open the page and check the saved content.
2. Check **Published** beside the save controls.
3. Check the **Publication period** under **Settings & more**.
4. Click **Save**.
5. Test the public page in a private browser window.

The publication period must include the current time, and the visitor must have access.

## Unpublish

Clear **Published** and click **Save**. The page stays in the admin for later editing. Editors with sufficient permissions may still see it.

Saving and publishing are different actions. However, saving edits to an already published page can update it immediately. Unpublishing does not recall downloaded files, emails, or copies already stored elsewhere.
