# Previewing content

::: aside
Some content types have no standalone public view. Check them on the page where the website uses them.
:::

1. Save your changes.
2. Click **View** or **Save and View**.
3. Check the title, text, images, links, and layout.
4. Return to the editor to correct anything that needs attention.

Your editor account may show unpublished or restricted content. Being able to preview it does not mean that visitors can see it. To check public availability, use a private browser window after publication.

Preview shows saved content. Keep **Published** unchecked while drafting a new page. Saving changes to an already published page may update the live page before you preview it.
