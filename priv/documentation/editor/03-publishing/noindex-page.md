# Keeping a page out of search engines

1. Open the page for editing.
2. Expand **SEO Content**.
3. Check **Ask Google to not index this page**.
4. Click **Save**.

This is an indexing request to search engines that respect it. It can take time for an already indexed page to disappear. It does not hide the page from visitors, restrict its URL, or necessarily remove it from your site's own search.

Use publication and access settings for content that should not be public. If the checkbox is missing or the page still appears in search results later, ask your website manager to check the site's search-engine settings.
