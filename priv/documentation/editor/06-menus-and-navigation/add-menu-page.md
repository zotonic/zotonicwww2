# Adding a page to a menu

1. Open the intended menu.
2. Click **Add menu item**, then choose **Add top** or **Add bottom**, or use an existing item's menu to add nearby.
3. Search for and select the page.
4. Move the new item to its intended position.
5. Check the menu on the website as a visitor.

The menu refers to the page; it does not duplicate it. Check that the page is published, within its publication period, and accessible to the intended audience. A menu entry for an unavailable page may be hidden or lead to an inaccessible page, depending on the design.

A page can be published without belonging to a menu.
