# Moving menu items

1. Open the menu editor.
2. Drag an item up or down to change its order.
3. Keep it at the same indentation if it should stay on the same level.
4. Drop it and check the tree before moving another item.
5. Reload and check the public menu.

Dragging left or right can change the parent and create a submenu. Moving a parent may move its nested items with it, so inspect the whole branch.

If the public order does not match, confirm that you edited the correct menu. A site's navigation may be built from a collection or another source instead.
