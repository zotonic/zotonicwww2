# Working with multiple menus

A site can have several menu pages, each with its own tree.

1. Find the menu page by its title or category in **All pages**.
2. Confirm where the website uses it: main navigation, footer, or a section.
3. Edit its items and check that specific area of the website.

The same content page can appear in more than one menu. Removing it from one menu does not remove it from the others.

Ask your website manager before creating a new menu for the public site. The design must be configured to display it. Give menu pages clear names so editors can tell them apart, and use their links when coordinating changes.
