# Creating submenus

1. Add both the parent page and child page to the menu.
2. Drag the child below the intended parent and slightly to the right.
3. Check the indentation: it should show the child nested under that parent.
4. Add more children if needed.
5. Check the public menu on desktop and mobile.

To return a child to the top level, drag it left until it aligns with the other top-level items.

The public menu design decides how many nested levels it supports and how visitors open them. Keep the structure shallow enough to understand. The menu hierarchy does not itself change a page's category, URL, or access permissions.
