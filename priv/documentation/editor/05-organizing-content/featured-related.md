# Featured and related content

To mark a page as featured, check **Featured** near the save controls and click **Save**. Your website must be designed to use this flag before it changes what visitors see.

For related content, open **Connected to** and add the relationship your site uses, such as **Relation** or **References**. Select the related page and check the public result.

Some sites choose related content automatically from shared keywords. If the displayed suggestions do not match your manual connections, ask your website manager how that section works.

Featured status does not publish a page, add it to a menu, or grant access. Related pages still need suitable publication and access settings for the intended readers.
