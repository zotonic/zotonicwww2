# Choosing categories

Choose a category when creating a page. On an existing page, its category appears below the title.

Use the most appropriate available category. For example, use an event category for an event rather than using an ordinary text page just because it contains text.

Categories can control the edit fields, public layout, search filters, and permitted connections. If a category is missing, your account may not be allowed to create it.

Use keywords for topics that can apply to many kinds of content. Avoid creating a new category just to group a few related pages. Ask your website manager before changing the category structure: it affects the whole site.
