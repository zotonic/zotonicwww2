# How Zotonic organizes content

Use each tool for a different purpose:

- A **category** says what the content is: an article, person, image, or event.
- A **keyword** says what it is about: gardening, education, or local history.
- A **connection** links it to another item, such as an author or related article.
- A **collection** groups selected items in an order.
- A **menu** provides navigation for visitors.

Start by creating the page in the right category. Add existing keywords and connections where they help readers find related content. Put the page in a collection or menu when the website calls for it.

Changing one of these does not automatically change the others. A published page can exist without a menu entry or collection membership.
