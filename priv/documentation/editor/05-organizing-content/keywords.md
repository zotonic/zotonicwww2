# Adding keywords or tags

1. Open the page and look in **Connected to** for **Keyword**, **Subject**, or your site's equivalent label.
2. Click **add** and search for an existing keyword.
3. Select the keyword that matches the topic.
4. Repeat for other useful topics and check the resulting connections.

Use the site's established spelling. Search before creating a new keyword so “Garden” and “Gardening” do not accidentally become competing labels. Create a new keyword only when your role and editorial guidelines allow it.

A keyword connection does not guarantee that a tag appears on the public page. Your website may instead use it for related content or filtering. Removing the connection leaves the keyword available for other pages.
