# Changing the order of content

1. Open the collection, menu, or page that contains the ordered items.
2. Use its drag handles or ordering controls to move the items.
3. Follow any save action shown by that editor.
4. Reload the edit view to check that the order was stored, then check the public page.

Menu and connection editors can save order changes immediately. A text form's **Save** button is not always what stores those changes.

An order belongs to a particular list or connection. Moving a page within one collection does not necessarily move it in another. Some public lists sort by date or title instead of your manual order; ask your website manager if the result differs.
