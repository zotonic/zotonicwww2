# What am I allowed to edit?

Your account's permissions can control whether you can create, view, edit, publish, delete, or upload particular content. They can depend on category, content group, ownership, and group membership.

Start with the content you have been assigned. If a button is missing or disabled, do not assume the website is broken.

When requesting access, send your website manager the page link and the action you need, such as “edit the summary” or “upload a PDF”. This is more useful than asking for full administrator access.

Access to edit a page and access to view it as a visitor are different. Check public availability separately when publishing.
