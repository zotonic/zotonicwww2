# Upload restrictions

If an upload fails, read the message before trying again.

1. Check the file size and actual file type.
2. Check that the file opens correctly on your computer.
3. Use a format and size accepted by your website.
4. If the error concerns permission, tell your website manager which type and size you need to upload and where it belongs.

Upload limits can depend on your account or group. A file extension alone does not make a file an allowed type. Renaming a file to look like an image or PDF will not fix its contents.

If processing fails after an upload, keep the original and report the media item's link and the error. Avoid creating many duplicate uploads while the first one is still processing.
