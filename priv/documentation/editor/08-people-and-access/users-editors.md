# Users and editors

A person page can describe an author or contact without giving that person permission to log in. A user has login details or another sign-in identity.

An editor is a user whose permissions allow editing particular content. Being able to log in does not automatically give access to all pages or admin tools.

Use your own account so colleagues can see who changed a page. Ask your website manager to arrange the right access for each new editor.

If you manage users, check existing person pages before creating a new one. Avoid duplicate profiles for someone who already appears as an author. Keep public biography information separate from private contact and account details.
