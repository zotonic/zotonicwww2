# Content ownership

The edit page shows when content was created and modified, and by whom. This helps you find the last editor when coordinating a change.

The creator, the last editor, the connected author, and the person responsible for maintaining a page can be different people. Changing an **Author** connection does not automatically transfer editing rights.

1. Check the page history shown near the title.
2. Check any editorial note and relevant connections.
3. Agree with the responsible editor before replacing substantial content.
4. Ask your website manager to change ownership or group access when needed.

Avoid editing the same page at the same time as another person. Save and communicate completed changes so someone else does not overwrite them with an older form.
