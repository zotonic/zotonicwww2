# Finding content

1. Open **All pages** from the dashboard.
2. Search for a distinctive word from the title.
3. Use the category and other available filters to narrow the results.
4. Open the matching page for editing. Check the title and category before changing it.

If you cannot find the page, clear the filters and try a shorter search. A page may have a different title in another language or belong to an unexpected category. The dashboard also lists recently modified content.

Your permissions limit which results you can see. Ask your website manager for the page link if you still cannot find it. Search for an existing image in **All media** before uploading another copy.
