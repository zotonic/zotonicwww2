# Importing and exporting recipients

1. Open the mailing list's **Recipients** view.
2. Use its upload/import action and read the format instructions.
3. Prepare the file exactly as requested. The standard recipient view describes one email address per line; do not assume it accepts an arbitrary spreadsheet.
4. Review any replace, remove, or update options before importing.
5. Inspect the resulting recipients and their status.

Use the download/export action when you need a local copy. Store it where only the intended people can access it.

Import only recipients who belong on that list. An import is not a reason to undo previous unsubscribe choices. If you need names or language preferences as well as addresses, check the import dialog's supported format with your website manager.

Try a small file containing only addresses approved for the test before importing a large list. Compare the recipients before and after the import, including disabled addresses and duplicates. If the dialog offers replacement, use it only when the uploaded file is intended to become the complete list. An exported file is not proof that all recipient preferences can be restored by importing it again.
