# Sending a mailing

1. Save the page and complete a test mailing.
2. Choose **Send mailing** from the page's **Mailing list** panel.
3. Select the intended mailing list.
4. Choose the email language and audience options. When using recipients' preferred languages, check the fallback and exclusion choices.
5. Review **Previous deliveries**. Sending again to everyone can produce duplicate emails.
6. Preview the email and continue to the review step.
7. Check the eligible recipients, language, and timing, then confirm the send using the final action shown.
8. Open the mailing run to follow its progress.

The initial subscriber total is only an estimate of the audience. The review step applies eligibility checks. After sending, messages already delivered cannot be recalled by unpublishing the page.
