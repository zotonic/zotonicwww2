# Managing recipients

1. Open the list's **Recipients** view.
2. Search or filter by address, status, or language as needed.
3. Use the recipient controls to add or edit an address and its details.
4. Check whether the recipient is enabled and which language they prefer.
5. Save the change and check the list again.

A subscribed address is not the same as a user account. Creating or editing a recipient does not give that person access to the admin.

Respect unsubscribe choices. Do not re-enable an address simply because it is missing from a mailing's eligible audience. It may be disabled, blocked, invalid, or excluded by the language or delivery-history options.
