# Scheduling a mailing

1. Save and test the mailing page.
2. Start **Send mailing** and choose the list, language, and audience.
3. In the timing section, choose the option offered for publication or **Send the mailing on a specific date and time**.
4. Enter the intended time and check the displayed time zone.
5. Review the audience and schedule before confirming.
6. Check the mailing's status afterwards to confirm that it is scheduled.

Publication-based sending depends on the page becoming published and reaching its publication start. A specific-date mailing has its own schedule; inspect the review step for any publication requirements.

To change a scheduled mailing, use the scheduling or cancellation controls shown on its status screen. Do not assume that editing an event date or unchecking Published cancels an already created mailing run.

After cancelling or rescheduling, reopen the run and check its recorded state and time. If it has already started, cancellation may stop only work still pending; messages already handed to a mail server can still arrive. Ask your website manager for help if the status does not confirm the change.
