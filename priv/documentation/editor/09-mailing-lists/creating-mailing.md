# Creating a mailing

1. Create or open the content page you want to send.
2. Write a clear title and concise body. Add suitable images and meaningful links.
3. Save the page.
4. Open **Settings & more → Mailing list** and choose **Preview mailing**.
5. Check the email layout and send a test before selecting the full audience.

An email can look different from the website page because it uses an email layout. Check links, image availability, and the unsubscribe information in the actual email.

Keep the intended recipients and language versions in mind while writing. Editing a page after sending does not change messages already in people's inboxes.
