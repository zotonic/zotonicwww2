# Why is the wrong image showing?

1. Open the page and inspect **Attached media**.
2. Check the order and remove unintended connections rather than deleting shared images.
3. Check images inserted in the body and any media blocks.
4. Open the selected media item to see whether its file was replaced.
5. Save relevant edits and check the public page.

The site may use the first attached image, an image from connected content, or a separate sharing image. Ask your website manager which source the layout uses if it is unclear.

If the website is correct but a social preview is wrong, the platform may be showing a cached preview. Check that before changing the page again.
