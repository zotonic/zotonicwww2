# Why does another language show old content?

1. Open the page's language tab for the language that looks wrong.
2. Compare the relevant fields with the source language.
3. Translate the changed text and save.
4. View the public page in that language.

Translations are separate text values. Editing English does not automatically rewrite Dutch, even if Dutch was originally copied from English.

If the field is empty, the site may use fallback text from another language. If the old text belongs to an image caption, menu item, or linked page, inspect that content too.

Use the public language switch when testing so you know which version you are viewing. Check the browser address and the page title.
