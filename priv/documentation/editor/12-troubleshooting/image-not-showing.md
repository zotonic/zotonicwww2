# Why isn’t an image showing?

1. Open the media item and confirm that the upload or processing completed.
2. Check that the intended page has the image under **Attached media**, or that it was inserted into the body text.
3. Save the page if you changed its body.
4. Check the media item's publication and access settings.
5. View the page in a private window.

Your website may display only certain connections or the first image in a list. Uploading a file to the library alone does not put it on a page.

For online media, check that the provider still allows the embed and whether cookie consent is required. Report the page and media links to your website manager if the item works in the admin but not publicly.
