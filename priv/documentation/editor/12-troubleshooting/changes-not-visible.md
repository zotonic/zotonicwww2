# My changes don’t appear on the website

1. Return to the edit page and confirm that the change was saved successfully.
2. Check that you edited the intended page and language.
3. Use **View** from that page instead of an old bookmark.
4. Reload the public page and compare it in a private window.
5. Check whether the visible content comes from a connected page, block, image summary, or another field.

Some designs do not display every admin field. A summary, featured flag, or connection can be stored without appearing in the current layout.

If the result is still wrong, give your website manager the edit link, public URL, changed field, language, and approximate save time. Mention whether the problem also appears in a private window.
