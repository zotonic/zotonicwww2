# I accidentally changed or deleted something

For unsaved text edits, use the editor's undo command or leave the form without saving if you are sure you do not need the changes. This does not undo connections or menu actions already saved separately.

For a saved page, check **Settings & more → Backup & Restore → List and restore an earlier version** if available. Compare the versions before restoring.

For deleted content or missing media, contact your website manager promptly. Give the old URL or title and the approximate time of the change. Recovery depends on enabled backups, retained revisions, and whether the file still exists.

Check related menus, connections, and media after recovery. Restoring page text is not necessarily a complete restoration of everything that used it.
