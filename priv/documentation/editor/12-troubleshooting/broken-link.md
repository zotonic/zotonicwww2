# A link is broken

1. Open the page containing the broken link and copy the destination for comparison.
2. Check whether the destination was renamed, moved, unpublished, restricted, or deleted.
3. For an internal page, replace the link using **Insert an internal link** when possible.
4. For an external website, check the current address with its owner or public site.
5. Save and test the link as a visitor.

If the broken link is in a menu or collection, edit that structure instead of the body text. For a file, check the media item and its download link.

If outside websites still use an old URL, ask your website manager about a redirect. Fixing one link on your site does not update links elsewhere.
