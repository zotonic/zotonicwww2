# Social sharing information

Social platforms may use the page's title, description, and image to build a link preview.

1. Check the main title and summary, and any **SEO Content** overrides.
2. Attach a suitable image in the place your website uses for sharing images.
3. Save and make sure the page and image are publicly accessible when intended.
4. Test the link using the platform's preview or inspection tool before sharing it widely.

The exact fields used depend on your website. Ask your website manager if the wrong image or text is selected.

Platforms cache previews. Editing the page may not update an existing preview immediately. Avoid repeatedly replacing the image until you have checked whether the platform is still using an old copy.
