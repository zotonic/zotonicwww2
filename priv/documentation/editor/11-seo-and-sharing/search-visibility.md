# Search engine visibility

A public page is not necessarily indexed, and a previously indexed page can remain in search results after a change.

To request exclusion, open **SEO Content**, check **Ask Google to not index this page**, and save. To allow indexing again, clear the option and save, then ask your website manager to check any site-wide or category-level restrictions.

The **Hide page from searches** option under **Advanced**, if available, concerns site queries that respect it. It is separate from search-engine indexing.

Neither option is access control. Use publication and permissions for private content. Search engines choose when to revisit a page, and a site's sitemap or indexing settings may also affect discovery.
