# Redirecting an old address

A redirect sends visitors from an old address to a current destination. It is useful when pages move or content is replaced.

1. Record the old URL and the exact replacement URL.
2. Check whether the old address already redirects correctly.
3. Ask your website manager to configure a redirect if your admin has no dedicated redirect tool.
4. Test the old address in a private browser window and check that it reaches the intended page.
5. Update links and menu entries you control to use the current destination.

Do not send every removed page to the home page: choose a relevant replacement when one exists. Avoid redirect loops and destinations that visitors cannot access. Redirect tools and automatic handling of old paths vary by site.
