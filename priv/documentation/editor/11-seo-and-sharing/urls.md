# Changing page URLs

A page's address can include a title-based slug or a custom page path.

1. Open the saved page with **View** and note its current URL.
2. If your role allows it, use **Customize page slug** under **SEO Content** for the title-like part of the address, or **Page path** under **Advanced** for a custom path.
3. Use a short, clear value and follow the site's naming conventions.
4. Save and test the new address in each relevant language.
5. Test the old address and arrange a redirect if it no longer reaches the right content.

Changing a title does not mean every site's URL changes in the same way. Avoid changing **Unique name** or **Unique uri** as a way to edit the public address: those fields have other purposes.
