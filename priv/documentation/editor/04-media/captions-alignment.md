# Image captions and alignment

1. Open the media properties for an image in **Content**.
2. Enter a **Caption** if the reader needs context or a credit.
3. Choose **Between text**, **Aligned left**, or **Aligned right**.
4. Choose a size and use **Crop image** only when the crop suits the subject.
5. Save the dialog and page, then check the result at both wide and narrow screen sizes.

In the standard rich-text media dialog, an empty caption uses the media summary. Enter a single `-` to suppress the caption for that use.

A caption is visible text beside an image. It is different from alternative text used to describe the image when it cannot be seen. The available sizes and crop behavior depend on the site design.
