# Uploading documents

1. Upload the file through **All media** or a page's media chooser.
2. Give the document a title that describes its contents.
3. Connect it to the page using the document or attachment connection your website displays, or add a link through the internal link chooser.
4. Save the page and test the link as a visitor.

Use link text that tells readers what they will get, for example “Download the garden handbook (PDF)”. The site's link or document layout determines whether the file opens directly, downloads, or opens a document page.

Check that the file is readable and accessible before publishing. If the document contains private information, ask your website manager to check access to the file as well as to the page linking to it.

Open the uploaded file through the page link, rather than checking only the original on your computer. Confirm that it is the intended version and that its text can be selected and searched. A scanned image of a document may need a text version. Include the file type and, for large downloads, the size in the link description.
