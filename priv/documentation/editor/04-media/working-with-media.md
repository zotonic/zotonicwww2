# Working with media

An image or file is a separate content item. A page can use it as attached media, an attachment, or an image inside its body text. Several pages can use the same item.

Before uploading, search **All media** for an existing copy. Reusing it keeps its title, description, and file in one place.

Choose how to use it:

- **Attached media** supplies images for the page layout, such as a lead image or gallery.
- **Insert media item** in the text editor places media at a particular point in the text.
- A document connection or link helps readers open or download a file.

Your website decides which connections it displays and how. Always view the page after adding media.
