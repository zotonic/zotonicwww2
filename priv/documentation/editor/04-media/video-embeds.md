# Adding video and other embedded media

1. Open the new-media or media-connection dialog.
2. Choose **Website or Embed** to use a supported video's public URL, or **Upload** for a video file if your site allows it.
3. Complete the dialog and inspect the new media item.
4. Attach it to a page or insert it in the body with **Insert media item**.
5. Save and check playback on the public page.

Uploaded video may need processing before it is ready. An online embed depends on the provider allowing it and the video remaining available. Cookie-consent settings can also delay loading an embed.

Use captions or provide a transcript where needed. If a provider or file type is unsupported, ask your website manager which format to use.
