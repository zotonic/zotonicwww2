# Replacing an image or file

1. Find the image or document in **All media** and open it.
2. Check **Connected from** or **Referrers** to see which pages use it.
3. Use the media replacement or upload action offered on its edit page.
4. Select the new file and complete the replacement.
5. Check the media item and the pages that use it.

Replacing the file changes the shared media item. Other pages using that item can show the replacement too. Upload a separate item if only one page needs a different file.

Check its title, summary, credits, and accessibility information after replacement. For a document, also test the download link. A browser or external service may temporarily show a cached copy.
