# Adding an existing image

1. Open the page that needs the image.
2. Under **Attached media**, click **add media item**.
3. Use the chooser's search to find the image by title.
4. Check its preview and choose the existing media item.
5. View the page to confirm that the correct image appears.

If you need the image inside a paragraph, use **Insert media item** in the text editor instead.

The same media item can serve several pages. Replacing its file may change all those uses. If another page needs a different crop, caption, or image, check which settings apply only to this use before changing the shared item.
