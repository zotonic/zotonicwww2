# Making images understandable

Describe the information an image contributes. For example, “Raised beds beside a wheelchair-accessible path” is more useful than “garden photo” when the page discusses access.

1. Give the media item a meaningful title and summary.
2. If your site's image form has an alternative-text field, fill it for the image's purpose on that page.
3. Use a visible caption for context or credits that all readers need.
4. Ask your website manager how the site creates alternative text if the field is not available.

The standard rich-text media dialog has a caption field, but does not offer a separate alternative-text field in every setup. Do not assume that adding a caption also sets the image's alternative text.

Put essential instructions in normal text too. Decorative images should not add distracting descriptions; how to mark them depends on the site.

For a chart, put the important figures or conclusion in the surrounding text. For an image used as a link, describe the destination or action. Avoid repeating a long caption as an image description. After saving, have the website manager check the rendered alternative text if you cannot verify it with your site's preview tools.
