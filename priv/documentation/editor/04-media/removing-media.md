# Removing media

To remove a single use, remove the item from **Attached media**, remove its document connection, or choose **Remove from text** for an image in the body. Then check the public page.

To delete the media item itself:

1. Open it in **All media**.
2. Inspect **Connected from** or **Referrers** and check known uses in body text.
3. Replace or remove any uses that should continue working.
4. Use **Delete…** and read the confirmation.

Deleting shared media can break several pages. Connection lists may not reveal links copied manually into text or used outside this website. If you only need a different image on one page, change that page's connection instead.
