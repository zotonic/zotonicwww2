# Finding media

1. Open **All media** from the dashboard.
2. Search by a distinctive word in the media title.
3. Use available category filters, such as image, video, or document.
4. Open the item and check its preview, title, and file details.

If you know a page that uses the file, open that page and follow the attached media or document connection. Check the text editor too: an image inside the body may be used separately from the page's lead image.

Your permissions affect which media items appear. Avoid uploading a new copy until you have checked the existing library and cleared any search filters.
