# Adding images in rich text

1. Place the cursor at the intended position in **Content**.
2. Click **Insert media item** in the editor toolbar.
3. Find an existing image or upload a new one, then select it.
4. Select the inserted image to open its media properties when you need to adjust it.
5. Save the properties, save the page, and view the result.

The properties can include a caption, alignment, size, crop, and link. Their final appearance depends on your website.

Use **Remove from text** in the media properties to remove this use of the image. That does not delete the media item from the library or remove it from other pages.
