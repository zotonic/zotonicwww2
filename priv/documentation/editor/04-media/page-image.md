# Adding an image to a page

1. Open the page for editing.
2. Find **Attached media** and click **add media item**.
3. Select an existing image or upload a new one.
4. Check the list of attached items. If the list supports dragging, put them in the required order.
5. Save any text changes and view the page.

An attached image is connected to the page. The site design decides whether to show it as a lead image, gallery, thumbnail, or something else. Some designs use the first suitable image.

If the image should appear at an exact place in the body text, insert it through the text editor. An attachment alone does not place it between paragraphs.
