# Duplicating or reusing content

Reuse an existing image, document, or page when it should stay the same wherever it appears. Add it through a media chooser, menu, collection, or connection.

To make an independent page:

1. Open the original and save any changes.
2. Choose **More → Make a duplicate**, or **Duplicate…** under **Settings & more**.
3. Review the dialog, enter the new title, and create the copy.
4. Check its text, languages, publication settings, and connections before publishing.

A duplicate is a separate page. Editing its text does not update the original. Connected media may still be shared; do not assume that duplication makes independent copies of every image and file.
