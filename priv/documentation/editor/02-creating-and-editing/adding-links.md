# Adding links

## Link to a page on this site

1. Select meaningful link text in the body.
2. Click **Insert an internal link**.
3. Find and select the destination page in the chooser.
4. Save the page and test the link.

Use the internal chooser when possible so the link identifies the Zotonic page.

## Link to another website or email address

Select the text and click **Insert/edit link**. Enter the full website address, including `https://`, or an email link such as `mailto:info@example.org`. Confirm the dialog and save.

Use link text such as “View the opening hours” rather than “click here”. Check that the destination is accessible to your readers; your editor account may be able to open private pages that visitors cannot.
