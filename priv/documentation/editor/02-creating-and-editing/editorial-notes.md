# Adding an editorial note

Use a note for information such as “Check the opening hours before publishing”. It is separate from the page's public body text.

1. Open the edit page.
2. Click **Add note** near the save controls, or **Edit note** if a note exists.
3. Write a short, specific message and save it in the note dialog.
4. Update or remove an outdated note when the work is finished.

A note is an aid for editors, not an approval workflow or a task assignment system. Do not put passwords or sensitive information in it. Other people who can edit the page may be able to read it.
