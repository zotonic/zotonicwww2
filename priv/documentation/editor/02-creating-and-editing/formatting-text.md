# Formatting text

1. Place the cursor in **Content**, or select text to change.
2. Use **Formats** for a paragraph or heading. Choose headings by their place in the text, not just their size.
3. Use the list buttons for steps or a set of related items.
4. Use bold or italic sparingly.
5. Save and check the public page, including on a narrow screen.

When pasting from another document, use your editor's plain-text paste option or **Clear formatting** if unwanted styles appear. Reapply headings and lists with the toolbar.

Use the page title as the main heading and start body sections below it. Avoid empty paragraphs or repeated spaces to position content: the layout changes between devices.
