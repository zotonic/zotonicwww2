# Adding content blocks

Some sites use blocks for sections such as text, a quote, media, or a linked page. The available block types and their appearance are set by the website.

1. Open the page for editing.
2. Click **add page block** below the main content.
3. Choose a block type and fill in its fields.
4. Use the block controls or drag handle to arrange the blocks, if available.
5. Save and view the page.

A block containing a page or image usually refers to existing content. Removing that block is different from deleting the referenced page or media item.

If the block you need is missing, ask your website manager which type to use. A block appearing in the admin does not guarantee that every page layout displays it.
