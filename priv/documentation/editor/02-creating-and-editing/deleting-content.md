# Deleting content

If a page should only disappear from public view, unpublish it first. Deletion removes the content itself and can affect menus, links, and connected pages.

1. Open the page and check its **Connected from** tab or **Referrers** link.
2. Arrange replacements for links or menu entries that still need a destination.
3. Choose **Delete…** under **More** or **Settings & more**.
4. Read the dialog carefully and confirm only when it names the intended page.
5. Check the affected parts of the website.

A protected page cannot be deleted until its protection is removed by someone allowed to do so. Recovery depends on the site's backup features and retained data. Do not rely on a universal trash folder or assume that media files can be recovered.
