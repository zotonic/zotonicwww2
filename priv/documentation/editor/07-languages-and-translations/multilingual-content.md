# Working with multilingual content

A multilingual page keeps its translations together. You normally edit one page with language tabs, rather than create a separate page for each language.

Fields such as the title, summary, and body can have a value for each language. Other properties and connections may be shared. Check the language label beside a field before changing it.

1. Open the page and choose its language tab.
2. Edit the translated fields.
3. Save and view the page in that language.
4. Repeat for other languages that need updating.

Changing the admin interface language does not translate your content. A language tab also does not prove that every field has been translated or reviewed. Check the whole page, including captions and linked documents.
