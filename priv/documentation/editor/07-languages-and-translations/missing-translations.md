# Missing translations and fallback languages

If a translated field is empty, the website may use text from another language. This is called a fallback. The site's settings and templates determine when that happens.

1. Open the page's language tab in the admin.
2. Check whether the relevant field contains a translation.
3. Add the missing text and save.
4. View the page using the public language switch.

If the wrong language still appears, check whether the text belongs to a connected image, person, document, or another page. Those items may need their own translations.

Ask your website manager about fallback rules and languages available to visitors. Do not create duplicate pages simply to work around a missing translation.
