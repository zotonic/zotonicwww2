# Language-specific URLs

Use the public language switch to open a page in the required language, then copy its URL if you need to share it.

A language code such as `/en/` or `/nl/` may appear in the address. The remaining path or title slug can also vary by language, depending on the site's configuration.

1. Translate and save the page.
2. View it in each public language.
3. Check the address and test any links you plan to share.

Use the internal page-link chooser when linking within the site. Avoid manually adding language prefixes to arbitrary URLs. If a translated address needs changing, follow your site's URL policy and check existing links and redirects afterwards.
