# Copying content between languages

1. Save the page and click **+ Translate**.
2. Choose the source language and the destination language.
3. Select **Copy texts**.
4. Leave **Overwrite existing texts with new translations** unchecked to fill empty destination fields only.
5. Click **Add translation**, edit the copied text into the target language, and save.

Select overwrite only when you intend to replace existing destination text. Check all affected fields before saving.

Copying text does not keep the two languages synchronized. Later changes to the source need a separate update in the translation. Shared images and connections may not need copying, but captions or language-specific documents still need checking.
