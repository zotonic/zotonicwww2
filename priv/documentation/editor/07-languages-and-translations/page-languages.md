# Seeing which languages a page has

Open the edit page and look at its language tabs. Click **+ Translate** to see **Current translations**.

For each language:

1. Open its tab.
2. Check the title, summary, body, and any other translated fields.
3. Use **Show translations** if available to compare the texts.
4. View the public page in that language.

A listed language means it is associated with the page. It does not mean that every field is filled, that an automatic translation is accurate, or that the public website offers that language.

If a needed language is absent from the choices, ask your website manager whether it is enabled for editing and publication.
