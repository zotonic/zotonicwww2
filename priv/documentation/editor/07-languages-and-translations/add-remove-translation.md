# Adding or removing a translation

To add a language, click **+ Translate**, choose the source and destination languages and a method, then click **Add translation**. Review the new text and save the page.

To remove one:

1. Save any changes you want to keep.
2. Open **+ Translate** and find the language under **Current translations**.
3. Click its **Delete translation** control and read the confirmation.
4. Save the page to store the removal.

Removing a language hides it from the form first. Saving then deletes its translated text from the page. Do not use this as a temporary “hide this tab” action.

The other language versions remain on the same page. Check the public language switch and any language-specific links afterwards.
