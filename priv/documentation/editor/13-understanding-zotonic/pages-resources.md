# Pages and resources

Zotonic stores an article, person, event, image, or collection as a **resource**. The admin often calls these pages because they share editing tools.

::: aside
For a technical explanation, see `model#rsc` in the developer reference.
:::

A resource has properties such as a title and category. It can also have media and connections to other resources.

Not every resource has a useful public page of its own. An image may be displayed inside an article, and a keyword may mainly be used to organize search results.

When editing, focus on the content's purpose and the page where visitors use it. A stored field or connection is only shown publicly if the website's design uses it.
