# How languages work

A multilingual resource keeps several translations together. Its title, summary, and body can have different text for each language while sharing the same resource identity.

Other fields and connections may be shared. This is why translating a page does not usually require making another article and reconnecting the same images.

The site's enabled languages, public language switch, and fallback rules determine which version visitors receive. Empty translated fields may fall back to another language.

Use language tabs to edit content and the public language switch to check it. The language of the admin buttons is a separate interface preference.

See `module#mod_translation` for the technical reference.
