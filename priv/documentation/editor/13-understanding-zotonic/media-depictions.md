# Media and depictions

::: aside
For developers, see `model#media`.
:::

A media resource is an item with an image, document, audio, video, or embed attached to it. It has its own title, properties, and access settings.

A **depiction** connection says that an image or media item represents another page. The admin commonly shows these items under **Attached media**. The site might use them as lead images or thumbnails.

Media can also be inserted into rich text. This lets an editor choose a position within the body. Attaching an image to the page and inserting it in the body are separate uses.

Because the media item is shared, replacing its file can affect several pages. Removing one connection normally leaves the media resource available elsewhere.
