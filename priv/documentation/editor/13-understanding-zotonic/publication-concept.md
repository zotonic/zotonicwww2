# Publication and visibility

A page can be saved without being public. These controls answer different questions:

- **Saved:** are the changes stored?
- **Published:** is the page marked for publication?
- **Publication period:** is it within its allowed start and end times?
- **Access:** may this visitor see it?
- **Menu or collection membership:** where is it listed?
- **Search indexing:** may a search engine include it in results?

A visitor normally needs publication, timing, and access to agree. Editors may have permission to view content that visitors cannot.

A menu entry does not grant access, and a no-index request does not make a page private. Test the public URL with the intended audience whenever those distinctions matter.
