# Developer guide

Build a Zotonic site, understand its applications, and use the development tools to check your work. These guides use a local example site named `garden`. Replace that name with your own site when following a task.

Use **Erlang/OTP 28**, the recommended Erlang version for these guides.

Start with Getting started for a first working page. Use Understanding Zotonic applications to find where a change belongs. The command-line and development tools collections help you inspect the running system. The reference collection lists every bundled CLI command in the checked source revision.
