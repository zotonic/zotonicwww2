# Getting started

Start with [Set up a local development environment](local-environment.md). It gives you a short path through installation, a running blog, and your first visible template change.

Choose one installation route: containers for a first try, native macOS/Linux when you want the tools installed locally, or Nix if you already use it. Each route leads back to the same `garden` example. The requirements and database pages are supporting instructions; you do not need to read every page before starting.

Once the first edit works, add a dynamic page and explore the development workflow. The collection below also provides the individual setup tasks for later reference.
