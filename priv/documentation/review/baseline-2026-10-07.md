## Import boundaries

The revision overlay owns English title, summary and body only. The local apply script also ensures English is in the language list and adds missing `hasreference`/`subject` edges. It preserves other translations, category, name, URL, publication properties and existing edges. It never writes `refers`.

All concrete adoption sources must be included in the final revision for their target. The XSS adoption now resolves to `doc_cookbook_security_templates_xss`, the canonical baseline name for source ID 2325. Multiple directory, status, translation, wires, shell and CLI sources are merged into one update per destination.

Preparation is offline. The apply script refuses changed input hashes and unresolved resources, media, predicates or connection targets before updating any text. Import the authored guide resources/media and controlled keywords first, then apply this overlay last. Original baseline seeding remains a separate missing-only operation for conversion tests.
