# Site administration

Use this guide to manage a site's accounts and settings, or to operate the server that runs it. Each task states the access you need. Having access to a site's admin does not automatically give you access to the server, its database, or other sites.

For browser work, start with People and permissions or Site settings and modules. For server work, start with Installation and deployment and establish backups before changing a live system. The examples use the site name `garden`; replace it with the intended site.

Use a test environment for your first attempt at a configuration change, restore, or upgrade. Keep the current working settings and a way to recover them. A completed command is not the final check: verify the affected page, login, media file, or email from the user's point of view.

New to Zotonic? Follow the developer guide's local installation walkthrough first. This guide covers running and maintaining sites; the editor guide covers everyday content work.
