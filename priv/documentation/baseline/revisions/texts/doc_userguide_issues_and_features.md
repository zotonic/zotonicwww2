# Report a problem or request a feature

Check whether the issue already exists in the [Zotonic issue tracker](https://github.com/zotonic/zotonic/issues). For a problem, describe the task, the steps you took, what you expected, and what happened. Include the Zotonic version or commit and relevant browser or server versions.

Use a small example and a screenshot when it makes the problem clearer. Remove passwords, tokens and private content from logs and images. For a feature request, explain the task it would help you complete and any current workaround.

An accepted issue is not a release-date commitment. Track progress in the issue or pull request. Follow the repository's private reporting instructions for security-sensitive problems.
